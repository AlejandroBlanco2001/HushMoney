Components

Bank Emails
Cloudflare Email Worker

You add a single forwarding rule in Gmail or Outlook. Bank notification emails are silently routed to your deployment's private address. Cloudflare converts the email to an HTTP POST and sends it to the Forwarder. No credentials shared, no IMAP server to configure.

Bank SMS
Android SMS Forwarder → Telegram Bot

A lightweight Android app (or Tasker rule) automatically forwards bank SMS messages to your private Telegram bot. iOS users can forward messages manually or switch to email alerts in their banking app settings.

Telegram Messages
Telegram Bot API

You create your own private bot via @BotFather — one command, takes two minutes. Forward bank notifications, photos of receipts, or voice notes directly to it. You own the bot token; nobody else can read its messages.

HushMoney Forwarder
Python 3.12 · channels/ sanitizer/ dispatcher/

The privacy boundary of the entire system. Every incoming message passes through the sanitizer before anything else happens. OTPs, account suffixes, card numbers, and full names are stripped here. Hermes never sees raw financial data. The Forwarder holds no state and no database.

Hermes Agent
NousResearch · github.com/NousResearch/hermes-agent

A self-improving personal AI agent that builds skills from experience. Hermes receives clean transaction payloads, categorizes them, stores them in the Ledger, and sends you summaries or questions. It runs inside the NVIDIA OpenShell sandbox so it can only reach the systems it's explicitly allowed to.

Transaction Ledger
SQLite · local to your Nebius volume

A single SQLite file on your server that holds every expense, category, description, and debt entry. No third-party database. No cloud sync. If you want a backup, copy the file. If you want to inspect it, open it with any SQLite viewer.

Network Egress Policy
NVIDIA OpenShell · config/openshell/policy.yaml

OpenShell enforces a kernel-level allowlist of hosts the agent can reach. Only the Nebius inference endpoint and the Telegram Bot API are permitted. Even if Hermes is tricked into making an unexpected network call, OpenShell blocks it before it leaves the sandbox.

Nebius Serverless — NVIDIA Inference
Nebius AI Cloud · NVIDIA open models

Hermes calls NVIDIA open models on Nebius Serverless to power its reasoning: understanding what a transaction means, picking the right category, generating a natural-language summary, and deciding whether to ask you a question. Nano for fast classification, Super and Ultra for richer reasoning tasks.

Telegram Notification Bot
Telegram Bot API · outbound only

The same bot you use to send messages in is also used by Hermes to reach you. It sends cash operation reminders ("You withdrew $100 — what was it for?"), ambiguous transaction questions, and your daily, weekly, and monthly summaries. No raw financial data is included in these messages.

How a transaction flows through the system

1
Bank notification arrives

Your bank sends an email or SMS: "Debit of $42.50 at Starbucks — account ending 1234. OTP: 882910"

2
Routed to HushMoney

Gmail's forwarding rule sends it to your Cloudflare Email Worker address, or your Android SMS relay sends it to your Telegram bot.

3
Forwarder sanitizes

The Forwarder strips the account suffix, the OTP, and any other sensitive detail. What remains: { amount: 42.50, merchant: "Starbucks", date: "...", type: "debit" }

4
Hermes receives the clean payload

The Forwarder POSTs the sanitized record to Hermes. This is the only thing Hermes ever sees — no OTPs, no account numbers.

5
Agent runs skills

Hermes calls the expense_tracker skill to store the transaction, then the categorizer skill to tag it (e.g., "dining"). Both skills read and write the local SQLite ledger.

6
Inference via Nebius

The categorizer calls an NVIDIA model on Nebius Serverless to determine the category. The OpenShell egress policy ensures this is the only external call the agent can make.

7
Done — or a question for cash ops

For digital transactions, nothing else happens. For cash withdrawals, Hermes sends your Telegram bot a message: "Cash withdrawal of $100 detected. What was it for?" You reply optionally.
