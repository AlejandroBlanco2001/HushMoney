## Make targets

Common commands are wrapped in a `Makefile`. Run `make` (or `make help`) to list them:

```bash
make run              # full stack, with LLM telemetry (OpenObserve on :5080)
make run-no-telemetry # full stack, without the OpenObserve sink
make down             # stop and remove the stack
make logs             # tail hermes + forwarder logs
make smoke            # POST a test transaction to the running gateway

make check            # everything CI runs: lint + format-check + typecheck + test
make test             # run the test suite
make lint / make fmt  # Ruff lint / auto-format
make typecheck        # Pyright (strict)
```

## Start the stack

`make run` wraps `./scripts/dev.sh --no-openshell`, which builds and starts the stack via
podman compose:

```bash
./scripts/dev.sh --no-openshell                 # full stack + telemetry
./scripts/dev.sh --no-openshell --no-telemetry  # skip the OpenObserve container
```

SQLite data persists in the `hermes-data` volume across restarts; rebuild after a Dockerfile
change with `make run` again (`dev.sh` always passes `--build`).

<Note>Bare `./scripts/dev.sh` runs Hermes inside an OpenShell sandbox from a prebuilt image —
that path does **not** include the local telemetry proxy. Use `--no-openshell` for telemetry.</Note>

## LLM telemetry

All model calls inside the Hermes container are routed through `llm_proxy.py`, which records
token usage and latency per call and pushes the metrics to **OpenObserve**. After `make run`,
open **http://127.0.0.1:5080**, log in with `OPENOBSERVE_ROOT_EMAIL` / `OPENOBSERVE_ROOT_PASSWORD`,
and inspect the `llm_usage` stream (grouped by `operation` and `model`).

<Note>If no data appears, check `OPENOBSERVE_AUTH` — ingestion is fail-open, so a mismatched
auth header silently drops events. It must be `Basic ` + base64 of `email:password` matching the
root credentials.</Note>

## Run the forwarder standalone

To run the forwarder without Docker (useful for iterating on sanitizer patterns):

```bash
cd forwarder
uv run python -m forwarder
```

Dry-run mode — logs emails but skips dispatching to Hermes:

```bash
DRY_RUN=true uv run python -m forwarder
```

## Test the gateway end-to-end

Inject a fake bank transaction directly:

```bash
source .env

curl -s -X POST http://localhost:8080/gateway \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HERMES_GATEWAY_SECRET" \
  -d '{
    "channel": "email",
    "from": "alerts@bancolombia.com.co",
    "subject": "Compra aprobada",
    "body": "Bancolombia le informa: Compra por $45,000 en RAPPI. Tarjeta terminada 1234."
  }'
```

Hermes will process the transaction and send a Telegram message. Watch the logs:

```bash
docker compose logs -f hermes
```

```bash
make test        # wraps scripts/run_tests.sh
```

## OpenShell sandbox (optional)

OpenShell wraps Hermes with kernel-level enforcement: filesystem (Landlock), syscalls (Seccomp BPF), and network egress (OPA proxy). The Nebius API key is managed by OpenShell and never enters the container.

**Requires:** Linux 6.2+, Podman 5.x or Docker 28+.

<Steps>
  <Step title="Install OpenShell">
    ```bash
    curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh
    openshell status
    ```
  </Step>
  <Step title="Configure the gateway">
    ```bash
    cp config/openshell/gateway.toml ~/.config/openshell/gateway.toml
    ```
  </Step>
  <Step title="Register the Nebius provider">
    ```bash
    openshell provider create nebius \
      --endpoint https://api.studio.nebius.ai/v1/ \
      --api-key $NEBIUS_API_KEY
    ```
  </Step>
  <Step title="Register secrets and policy">
    ```bash
    openshell secret set TELEGRAM_BOT_TOKEN "$TELEGRAM_BOT_TOKEN"
    openshell secret set TELEGRAM_CHAT_ID "$TELEGRAM_CHAT_ID"
    openshell secret set HERMES_GATEWAY_SECRET "$HERMES_GATEWAY_SECRET"
    openshell policy set hushmoney --policy config/openshell/policy.yaml --wait
    openshell profile register config/openshell/profile.yaml
    ```
  </Step>
  <Step title="Start sandboxed">
    ```bash
    docker build -t hushmoney-hermes .
    openshell sandbox create --from hushmoney --name hushmoney-1
    docker compose up forwarder
    ```
  </Step>
</Steps>
