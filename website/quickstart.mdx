## Prerequisites

Before running the setup script, you need:

<AccordionGroup>
  <Accordion title="AWS EC2 instance">
    1. Open the [AWS EC2 console](https://console.aws.amazon.com/ec2/)
    2. Launch instance → **Amazon Linux 2023 AMI**
    3. Instance type: **t3.small** (recommended) or t2.micro (free tier)
    4. Key pair: create a new one (`hushmoney`), download the `.pem` file
    5. Security group: allow inbound SSH (port 22) from your IP
    6. Launch, then attach an **Elastic IP** so the address stays stable across restarts
  </Accordion>
  <Accordion title="Telegram bot">
    1. Open Telegram and message [@BotFather](https://t.me/BotFather)
    2. Send `/newbot` and follow the prompts
    3. Copy the bot token — it looks like `123456789:ABCdef...`
    4. Get your personal chat ID by messaging [@userinfobot](https://t.me/userinfobot)
  </Accordion>
  <Accordion title="Nebius API key">
    Sign up at [nebius.ai](https://nebius.ai), create a project, and generate an API key from the **Token Factory** section.
  </Accordion>
  <Accordion title="Gmail App Password">
    1. Enable IMAP: Gmail Settings → Forwarding and POP/IMAP → **Enable IMAP**
    2. Generate App Password: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → name it "hushmoney"
    3. Copy the 16-character password (no spaces)

    <Note>Outlook users: set up a forwarding rule to send bank emails to Gmail, then use your Gmail address and App Password here.</Note>
  </Accordion>
</AccordionGroup>

## Setup

<Steps>
  <Step title="Clone the repo">
    ```bash
    git clone https://github.com/AlejandroBlanco2001/Untyped.git
    cd Untyped
    ```
  </Step>
  <Step title="Create your .env">
    ```bash
    cp .env.example .env
    ```
    Fill in the required values — see the [Environment Variables](/configuration/environment-variables) reference for the full list.
  </Step>
  <Step title="Run setup">
    ```bash
    ./scripts/setup.sh
    ```

    On first run, the script will:
    - Install Docker and Docker Compose on the EC2 instance
    - Clone the repo to `/home/ec2-user/hushmoney`
    - Push your secrets as a remote `.env`
    - Start the full stack via `docker compose up -d`

    Subsequent runs just push updated secrets and restart the stack.
  </Step>
  <Step title="Verify">
    Open Telegram, find your bot by username, and send `/start`. Then send `/status` — Hermes should reply with agent health and the last transaction it saw.
  </Step>
</Steps>

## Load demo data (optional)

To pre-populate the database with 3 months of realistic fake transactions:

```bash
./scripts/seed_demo.sh
```

This seeds Bancolombia checking, Bancolombia credit, and Nequi accounts with salary credits, groceries, transport, subscriptions, and sample debts. Useful for demos and judging.

## Useful commands

```bash
# Tail logs on EC2
ssh -i ~/.ssh/hushmoney.pem ec2-user@<EC2_HOST> \
  'cd hushmoney && docker compose logs -f'

# Redeploy after a git push
ssh -i ~/.ssh/hushmoney.pem ec2-user@<EC2_HOST> \
  'cd hushmoney && git pull && docker compose up -d --build'

# Rotate Nebius API key
./scripts/setup.sh --rotate-key
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Permission denied (publickey) when running setup.sh">
    - Confirm `EC2_KEY_FILE` in `.env` points to the correct `.pem` file
    - Run `chmod 400 ~/.ssh/hushmoney.pem`
    - Check that the EC2 security group allows SSH from your current IP
  </Accordion>
  <Accordion title="Forwarder not picking up emails">
    - `BANK_SENDER_EMAILS` must match the exact sender address in your bank's emails
    - Confirm IMAP is enabled in Gmail settings
    - SSH into EC2 and run `docker compose logs forwarder` to see poll output
  </Accordion>
  <Accordion title="Telegram: Chat not found">
    The bot has never received a message from your account. Open Telegram, find your bot, and send `/start` to open the chat.
  </Accordion>
</AccordionGroup>
