HushMoney runs as a Docker Compose stack. If Docker is installed, it runs. No cloud account required.

## Prerequisites

<AccordionGroup>
  <Accordion title="Docker">
    Install [Docker Desktop](https://docs.docker.com/get-docker/) (Mac/Windows) or Docker Engine (Linux). Docker Compose v2 is included.
  </Accordion>
  <Accordion title="Telegram bot">
    1. Message [@BotFather](https://t.me/BotFather) on Telegram
    2. Send `/newbot` and follow the prompts
    3. Copy the bot token — it looks like `123456789:ABCdef...`
    4. Get your personal chat ID by messaging [@userinfobot](https://t.me/userinfobot)
  </Accordion>
  <Accordion title="Nebius API key">
    Sign up at [nebius.ai](https://nebius.ai), create a project, and generate an API key from the **Token Factory** section.
  </Accordion>
  <Accordion title="Email account with IMAP">
    You need an email account that receives your bank notifications and supports IMAP with an app password. See [Bank Setup](/configuration/bank-setup) for compatible providers.
  </Accordion>
</AccordionGroup>

## Deploy

<Steps>
  <Step title="Clone the repo">
    ```bash
    git clone https://github.com/AlejandroBlanco2001/Untyped.git
    cd Untyped
    ```
  </Step>
  <Step title="Create your .env">
    ```bash
    cp .env.example .env
    ```
    Fill in the required values. See [Environment Variables](/configuration/environment-variables) for the full reference.

    The minimum required set to get started:
    ```bash
    NEBIUS_API_KEY=...
    TELEGRAM_BOT_TOKEN=...
    TELEGRAM_CHAT_ID=...
    IMAP_HOST=imap.gmail.com
    IMAP_USERNAME=you@gmail.com
    IMAP_PASSWORD=your-app-password
    BANK_SENDER_EMAILS=alerts@yourbank.com
    HERMES_GATEWAY_SECRET=any-random-string
    ```
  </Step>
  <Step title="Start the stack">
    ```bash
    docker compose up -d
    ```

    This starts three containers:
    - `hermes` — the AI agent
    - `forwarder` — email poller and sanitizer
    - `sms-listener` — Telegram SMS intake (optional, see [iPhone SMS](/configuration/iphone-sms))

    All containers restart automatically on reboot (`restart: unless-stopped`).
  </Step>
  <Step title="Verify">
    Open Telegram, find your bot by username, and send `/start`. Then send `/status` — Hermes should reply confirming it's running.
  </Step>
</Steps>

## Load demo data (optional)

To pre-populate the database with 3 months of realistic fake transactions:

```bash
./scripts/seed_demo.sh
```

Seeds salary credits, groceries, transport, subscriptions, and sample debts across three accounts. Useful for trying the bot before your bank notifications arrive.

## Keep it running

The stack manages its own uptime — containers restart automatically after crashes or reboots. To check status at any time:

```bash
docker compose ps
docker compose logs -f
```

To update to the latest version:

```bash
git pull && docker compose up -d --build
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Forwarder not picking up emails">
    - `BANK_SENDER_EMAILS` must exactly match the sender address in your bank's emails
    - Confirm IMAP is enabled on your email account
    - Run `docker compose logs forwarder` to see what's happening
  </Accordion>
  <Accordion title="Telegram: Chat not found">
    The bot has never received a message from you. Open Telegram, find your bot by username, and send `/start` to open the chat.
  </Accordion>
  <Accordion title="Hermes container keeps restarting">
    Check that `NEBIUS_API_KEY` and `HERMES_GATEWAY_SECRET` are set correctly in `.env`, then run `docker compose logs hermes`.
  </Accordion>
</AccordionGroup>
