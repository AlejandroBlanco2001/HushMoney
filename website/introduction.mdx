HushMoney is a personal AI assistant that intercepts bank notifications from email and SMS, strips all sensitive data at the edge, and hands clean transaction signals to an AI agent that tracks, categorizes, and summarizes your spending — automatically.

No manual entry. No spreadsheets. Just ask.

## How it works

<Steps>
  <Step title="Bank sends a notification">
    An email or SMS arrives from your bank — a purchase confirmation, a transfer, a cash withdrawal.
  </Step>
  <Step title="Forwarder sanitizes it">
    The forwarder strips OTPs, full account numbers, recipient names, and any other PII. Matched notifications produce a clean payload (amount, merchant, date, type). Unmatched financial notifications are forwarded to the agent with redacted text so new patterns can be learned — raw values never cross the boundary.
  </Step>
  <Step title="Hermes Agent processes it">
    The agent runs on **NVIDIA Nemotron 3 Nano** via **Nebius Serverless**. It categorizes the transaction, stores it in SQLite, and optionally sends you a Telegram reminder for cash operations.
  </Step>
  <Step title="You ask questions">
    At any time, message your bot on Telegram: *"what did I spend last week?"*, *"show me my subscriptions"*, *"Carlos owes me $50,000 from lunch"*.
  </Step>
</Steps>

## Built with

| Layer | Technology |
|---|---|
| AI Agent | [Hermes Agent](https://hermes-agent.nousresearch.com) — NousResearch |
| Agent Sandbox | NVIDIA OpenShell |
| Model | `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` via Nebius Serverless |
| SMS listener | Pyrogram (MTProto user client) |
| Forwarder | Python 3.12 |
| Database | SQLite |
| Notifications | Telegram Bot API |
| Hosting | AWS EC2 (t3.small) |
