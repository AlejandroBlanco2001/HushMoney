HushMoney extends Hermes Agent through a **skills system** — discrete, composable capabilities that the agent can invoke as tools. Each skill is a directory of Python scripts that Hermes calls at runtime.

## Adding a new skill

Drop a new directory into `skills/` with the following structure:

```
skills/my-skill/
├── skill.yaml        # skill metadata and tool definitions
└── scripts/
    ├── my_action.py  # one script per tool
    └── ...
```

Hermes picks up new skills automatically on the next restart — no changes to the agent or Dockerfile required.

See `AGENTS.md` for the full skill authoring guide.
