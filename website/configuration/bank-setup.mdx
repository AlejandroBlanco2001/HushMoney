---
title: Bank Setup
description: Configure your bank email notifications for automatic capture.
---

HushMoney captures transactions from bank email notifications by polling your inbox via IMAP. The forwarder connects directly to your email account every 5 minutes — no webhooks, no third-party routing, no domain required.

## Step 1 — Enable bank email alerts

In your bank's app or website, enable transaction notifications via email. Look for:

- "Email alerts" / "Email notifications"
- "Transaction alerts"
- "Spending notifications"

Enable alerts for purchases, transfers, cash withdrawals, and any other transaction types you want to track.

## Step 2 — Note the sender address

Check one of the notification emails your bank sends and copy the exact **From** address. It usually looks like `alerts@yourbank.com` or `no-reply@notifications.bank.com`.

Add it to `.env`:

```bash
BANK_SENDER_EMAILS=alerts@bancolombia.com.co
```

For multiple banks:

```bash
BANK_SENDER_EMAILS=alerts@bancolombia.com.co,no-reply@nequi.com,notificaciones@davivienda.com
```

## Step 3 — Choose a compatible email provider

The forwarder authenticates via IMAP using an app password. Use any provider from the list below — forward your bank notifications there if they go to a different address.

<AccordionGroup>
  <Accordion title="Gmail (recommended)">
    1. Enable IMAP: Gmail Settings → **Forwarding and POP/IMAP** → Enable IMAP
    2. Generate an App Password: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → name it "hushmoney"
    3. Copy the 16-character password (no spaces)

    ```bash
    IMAP_HOST=imap.gmail.com
    IMAP_PORT=993
    IMAP_USERNAME=you@gmail.com
    IMAP_PASSWORD=abcd efgh ijkl mnop   # paste as-is, spaces ignored
    ```

    <Note>Google requires 2-Step Verification to be enabled before you can create App Passwords.</Note>
  </Accordion>
  <Accordion title="Yahoo Mail">
    1. Go to [Account Security](https://login.yahoo.com/account/security) → **Generate app password**
    2. Select "Other app" → name it "hushmoney" → copy the password

    ```bash
    IMAP_HOST=imap.mail.yahoo.com
    IMAP_PORT=993
    IMAP_USERNAME=you@yahoo.com
    IMAP_PASSWORD=your-app-password
    ```
  </Accordion>
  <Accordion title="iCloud Mail">
    1. Go to [appleid.apple.com](https://appleid.apple.com) → Sign-In and Security → **App-Specific Passwords**
    2. Generate a password → name it "hushmoney"

    ```bash
    IMAP_HOST=imap.mail.me.com
    IMAP_PORT=993
    IMAP_USERNAME=you@icloud.com
    IMAP_PASSWORD=your-app-specific-password
    ```
  </Accordion>
  <Accordion title="Fastmail">
    1. Go to Settings → Privacy & Security → **App Passwords** → New App Password
    2. Name it "hushmoney" → copy the password

    ```bash
    IMAP_HOST=imap.fastmail.com
    IMAP_PORT=993
    IMAP_USERNAME=you@fastmail.com
    IMAP_PASSWORD=your-app-password
    ```
  </Accordion>
  <Accordion title="Zoho Mail">
    1. Go to Zoho Account → Security → **App Passwords** → Generate
    2. Name it "hushmoney" → copy the password

    ```bash
    IMAP_HOST=imap.zoho.com
    IMAP_PORT=993
    IMAP_USERNAME=you@zohomail.com
    IMAP_PASSWORD=your-app-password
    ```
  </Accordion>
</AccordionGroup>

<Warning>
  Providers that require OAuth (Microsoft 365, Outlook.com, Hotmail) are not supported — they do not allow IMAP authentication with a simple password or app password.
</Warning>

## Supported banks

The forwarder ships with pre-built parsing patterns for:

| Bank | Country | Channel |
|---|---|---|
| Bancolombia | Colombia | Email, SMS |
| Nequi | Colombia | SMS |

For banks not on this list, use the [Bank Learning](/skills/bank-learning) skill to teach Hermes new formats interactively — no code required.

## Verify your setup

With the stack running:

```bash
docker compose logs -f forwarder
```

You should see polling lines like:

```
[forwarder] polling INBOX for alerts@bancolombia.com.co...
[forwarder] 1 unseen message(s) found
[forwarder] dispatched: {"amount": 45000, "merchant": "RAPPI", ...}
```
