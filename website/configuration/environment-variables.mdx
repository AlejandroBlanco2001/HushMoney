---
title: Environment Variables
description: Complete reference for every variable in .env.
---

Copy `.env.example` to `.env` and fill in your values. Never commit `.env` — it is in `.gitignore`.

## Telegram

| Variable | Required | Description |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Yes | Bot token from [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_BOT_ID` | Yes | The number before the `:` in your bot token |
| `TELEGRAM_CHAT_ID` | Yes | Your personal Telegram user ID (get it from [@userinfobot](https://t.me/userinfobot)) |
| `BOT_USERNAME` | Yes | Your bot's `@handle` from BotFather |
| `TELEGRAM_API_ID` | Yes | From [my.telegram.org](https://my.telegram.org) → API Development Tools |
| `TELEGRAM_API_HASH` | Yes | From [my.telegram.org](https://my.telegram.org) → API Development Tools |
| `TELEGRAM_SESSION_STRING` | Auto | Generated by `dev.sh` on first run — do not set manually |
| `TELEGRAM_WEBHOOK_URL` | Optional | Public URL for the Telegram webhook (only needed for the webhook intake mode) |
| `TELEGRAM_WEBHOOK_SECRET` | Optional | Random secret to validate webhook requests |

<Note>
  `TELEGRAM_CHAT_ID` is your personal user ID, not the bot's ID. It is the sole account allowed to interact with the bot.
</Note>

## Nebius / NVIDIA inference

| Variable | Required | Description |
|---|---|---|
| `NEBIUS_API_KEY` | Yes | API key from [Nebius Token Factory](https://studio.nebius.com) |

The model used is `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B`. This is set in `config/hermes.yaml` and does not need to be in `.env`.

## AWS EC2

| Variable | Required | Description |
|---|---|---|
| `EC2_HOST` | Yes | Elastic IP of your EC2 instance |
| `EC2_USER` | No | SSH user — defaults to `ec2-user` |
| `EC2_KEY_FILE` | Yes | Path to your `.pem` key pair, e.g. `~/.ssh/hushmoney.pem` |

## Hermes gateway

| Variable | Required | Description |
|---|---|---|
| `HERMES_GATEWAY_URL` | Yes | URL of the gateway server inside the container. Local: `http://localhost:8080/gateway`. EC2 (compose network): `http://hermes:8080/gateway` |
| `HERMES_GATEWAY_SECRET` | Yes | Shared secret between the forwarder and gateway. Generate with `openssl rand -hex 32` |

## Email (IMAP)

| Variable | Required | Description |
|---|---|---|
| `IMAP_HOST` | Yes | IMAP server — `imap.gmail.com` for Gmail |
| `IMAP_PORT` | No | Defaults to `993` (SSL) |
| `IMAP_USERNAME` | Yes | Your full email address |
| `IMAP_PASSWORD` | Yes | 16-character Gmail App Password — regular passwords are blocked |
| `IMAP_MAILBOX` | No | Mailbox to poll — defaults to `INBOX` |
| `BANK_SENDER_EMAILS` | Yes | Comma-separated list of sender addresses to watch, e.g. `alerts@bancolombia.com.co,no-reply@nequi.com` |
| `POLL_INTERVAL_SECONDS` | No | How often to poll — defaults to `300` (5 minutes) |
