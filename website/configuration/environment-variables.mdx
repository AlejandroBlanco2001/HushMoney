---
title: Environment Variables
description: Complete reference for every variable in .env.
---

Copy `.env.example` to `.env` and fill in your values. Never commit `.env` — it is in `.gitignore`.

## Required

### Telegram

| Variable | Description |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Bot token from [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_BOT_ID` | The number before the `:` in your bot token |
| `TELEGRAM_CHAT_ID` | Your personal Telegram user ID — get it from [@userinfobot](https://t.me/userinfobot) |
| `BOT_USERNAME` | Your bot's `@handle` from BotFather |

<Note>`TELEGRAM_CHAT_ID` is your personal user ID, not the bot's. Only this account can interact with the bot.</Note>

### Nebius / NVIDIA inference

| Variable | Description |
|---|---|
| `NEBIUS_API_KEY` | API key from [Nebius Token Factory](https://studio.nebius.com) |

The model (`nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B`) is set in `config/hermes.yaml` — no env var needed.

### Email (IMAP)

| Variable | Description |
|---|---|
| `IMAP_HOST` | IMAP server hostname — e.g. `imap.gmail.com` |
| `IMAP_USERNAME` | Your full email address |
| `IMAP_PASSWORD` | App password from your email provider |
| `BANK_SENDER_EMAILS` | Comma-separated sender addresses to watch — e.g. `alerts@bancolombia.com.co,no-reply@nequi.com` |

See [Bank Setup](/configuration/bank-setup) for supported providers and how to generate an app password.

### Gateway

| Variable | Description |
|---|---|
| `HERMES_GATEWAY_SECRET` | Shared secret between the forwarder and Hermes. Generate with `openssl rand -hex 32` |

## Optional

### Email (IMAP)

| Variable | Default | Description |
|---|---|---|
| `IMAP_PORT` | `993` | IMAP port (SSL) |
| `IMAP_MAILBOX` | `INBOX` | Mailbox to poll |
| `POLL_INTERVAL_SECONDS` | `300` | How often to check for new emails (seconds) |

### Telegram SMS intake

Only needed if you want to capture bank SMS via iPhone Shortcuts. See [iPhone SMS](/configuration/iphone-sms).

| Variable | Description |
|---|---|
| `TELEGRAM_API_ID` | From [my.telegram.org](https://my.telegram.org) → API Development Tools |
| `TELEGRAM_API_HASH` | From [my.telegram.org](https://my.telegram.org) → API Development Tools |
| `TELEGRAM_SESSION_STRING` | Generated automatically by `dev.sh` on first run — do not set manually |
| `TELEGRAM_WEBHOOK_URL` | Public URL for the Telegram webhook (webhook intake mode only) |
| `TELEGRAM_WEBHOOK_SECRET` | Random secret to validate webhook requests |

### Gateway

| Variable | Default | Description |
|---|---|---|
| `HERMES_GATEWAY_URL` | `http://hermes:8080/gateway` | URL of the gateway inside the Docker network — only change this for non-Compose deployments |
